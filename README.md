# Task Master — Gestor de tareas

Aplicación web para gestionar tareas personales con autenticación de usuarios, validaciones de datos y pruebas automatizadas.

## Objetivo

Desarrollar una aplicación completa mientras aprendo los fundamentos de la programación, el desarrollo web y las buenas prácticas de ingeniería de software.

## Funcionalidades previstas

- [ ] Registro de usuarios.
- [ ] Inicio y cierre de sesión.
- [ ] Creación de tareas.
- [ ] Consulta de tareas.
- [ ] Edición de tareas.
- [ ] Eliminación de tareas.
- [ ] Marcado de tareas como completadas.
- [ ] Protección de las tareas de cada usuario.
- [ ] Validación de datos en frontend y backend.
- [ ] Pruebas automatizadas de integración.

## Tecnologías

- **Frontend:** Next.js, React, TypeScript y Tailwind CSS.
- **Backend:** Node.js, Express y TypeScript.
- **Base de datos:** PostgreSQL.
- **ORM:** Prisma.
- **Validación:** Zod.
- **Autenticación:** cookies HttpOnly y sesiones seguras.
- **Pruebas:** Jest o Vitest.

## Arquitectura

El frontend se encarga de la interfaz de usuario.

El backend procesa las peticiones, valida los datos, aplica las reglas del negocio y se comunica con la base de datos.

PostgreSQL almacena los usuarios y sus tareas.

## Estado del proyecto

En preparación. El desarrollo se realizará progresivamente, desde los fundamentos de programación hasta la implementación, las pruebas y la documentación.

## Aprendizajes

Este proyecto servirá como práctica de operaciones CRUD, separación de responsabilidades, autenticación, diseño de API, bases de datos relacionales y pruebas de integración.
