# Plan de aprendizaje — Task Master

## Objetivo

Construir un gestor de tareas web desde cero mientras aprendo programación y buenas prácticas de desarrollo.

## Etapas

1. Fundamentos de programación.
2. JavaScript y TypeScript.
3. Git y GitHub.
4. Frontend con Next.js, React y Tailwind CSS.
5. Backend con Node.js y Express.
6. Validación de datos con Zod.
7. Base de datos PostgreSQL y Prisma ORM.
8. Autenticación y autorización.
9. Pruebas automatizadas.
10. Documentación y publicación.

## Reglas de aprendizaje

- Comprender cada concepto antes de avanzar.
- Escribir y probar código en pequeños pasos.
- Documentar los errores y sus soluciones.
- Usar nombres claros y convenciones consistentes.
- No guardar contraseñas, tokens ni secretos en GitHub.
